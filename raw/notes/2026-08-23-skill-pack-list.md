## Thesis as pasted

The point of a skill is not more lines of code. It is packaging a repeated workflow as an SOP:

- how to review UI
- how to check an API
- how to plan a database
- how to organize docs
- how to do architecture review
- how to hand off a task

A stable process stops the agent from retrying a known failure and burning tokens.

The human later wrote a Smoke-problem script as Hook + SOP, and asked whether making their own Skill is a good method.

The Smoke script itself was not attached.
