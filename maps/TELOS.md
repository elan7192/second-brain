# TELOS

Why this vault exists.

## End

A compiled second brain that answers from pages it already maintains. The human curates sources and decisions. The agent files, links, and flags.

## Not the end

A chat log. A filing cabinet. A bot that posts, pays, or sends.

## Tests

- A question is answered from [[index]] plus linked pages.
- A new source updates more than one page.
- `MEMORY.md` only holds facts that change an answer.
- [[contradictions]] lists unresolved conflicts instead of hiding them.
