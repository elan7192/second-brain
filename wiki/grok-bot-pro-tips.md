# Grok Bot pro tips

Ten tips from the @bot team, collected by Ben Lang.

Source: [[src-benln-grok-bot-pro-tips]]. lan E share.

1. Ask Grok Bot to set up Peekaboo on your Mac for more OpenClaw-like features.
2. Use bots as roles (designer, engineer, PM). Each has its own system prompt and routines.
3. Use channels to organize projects and workstreams. Same bot can work across many channels.
4. Avoid scheduled routines that run too frequently. Hourly or a few times a day is usually enough.
5. For recurring tasks, give that to a fresh bot. Keep chatting with main bots (like a chief of staff).
6. Customizable rules to allow or deny actions. For bots on X, Gmail, etc., consider blocking write/destructive actions and ask for approval first.
7. Feed the bot examples from previous handwritten content. It gets better over time.
8. Make a Chief of Agents. Give it the rules every bot should follow: draft only, naming, voice, allowed tools. Ask it to create new bots with the same rules.
9. For routines: could a real human teammate do this job? If yes, build it. If no, optimize first. Never run a routine every 5 minutes.
10. Name-driven behavior. Bots act from the name given at creation. The role is legible from the name.
