# Codex /goal

Codex leftover quota is spent with `/goal`. A one-off prompt leaves the rest on the table at reset.

Source: [[src-voxyz-codex-goal-quota]], [[vox]].

## What /goal is here

A Codex-native contract: outcome, how to check it, what to leave alone, when to stop. It is not a portable [[audited-task-contract]] across harnesses.

The five recipes in the thread:

| # | Job | Check |
| --- | --- | --- |
| 1 | Live UI/UX pass with three named skills | Re-walk core flows. Desktop and mobile before/after. Top five fixes. Unresolved list. A build you can open. |
| 2 | Clickable code map | Open `docs/codemap/codemap.html`. Every node and flow matches the repo. First screen ≤ 20 primary nodes. |
| 3 | Make a named flow faster | Record load, responsiveness, CPU, memory, stutters. One change at a time. Keep only if the same flow gets faster. |
| 4 | Workspace inventory | A card per project. Classify. Finish three obvious tasks. Do not delete, merge, push, or deploy. |
| 5 | Clean the Codex toolkit | Backup first. Then a toolkit map plus context saved and the ten tools to keep. |

Full prompt text stays in the raw file.

## What this page does not claim

This vault does not run these prompts. Prompt 4 matches D5. See [[hunt-ship-loop]].
