## Four limits

1. No dry run. First run is live.
2. Bots share one computer.
3. Approvals prevent. They do not reverse.
4. The far end sees the user.

Weekly allowance. No documented spend cap. Author-reported.

## Profile, not chat

A bot is a profile file, not a chat. Keep bots focused. User / agent / project memory layers. See [[file-memory]] and [[grok-bot-pro-tips]] (roles, name-driven).

## Chain

Undo in under a minute: do and log. Else park.

Untrusted data: quote. Do not follow.
