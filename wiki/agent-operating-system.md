# Agent operating system

Synthesis of the compiled posts through [[src-omarsar-adversarial-review]]. File this back so later sessions do not rebuild it from the posts.

## Stack

Five layers, one vault.

1. **Compile, do not retrieve.** [[llm-wiki]] + [[tokens-as-capital]]. `raw/` is input. `wiki/` is the brain. `output/` is built from the wiki.
2. **Remember only what changes answers.** [[memory-engineering]] + [[memory-ablation]]. Capture is a filter. Adjectives die. Conflicts `flag_conflict`.
3. **Share a contract, not a chat.** [[audited-task-contract]] + [[harness-routing]] + [[entropy-gate]]. Planner proposes. Deterministic controller commits. Isolated worktrees. Validated diffs. [[adversarial-review]] freezes the artifact while a reviewer and critic argue, then the writer edits.
4. **Check instead of wishing.** [[verifiable-instructions]] + [[self-verification]] + [[anti-slop]]. Every schema rule has a check. High-risk answers get scored against citations. [[ultra-mode]] is the coding-agent product of that loop: N isolated worktrees, [[probabilistic-pivot-tournament]], uncommitted apply.
5. **Keep a human gate.** [[hunt-ship-loop]]. File first. Scouts write quietly. Vault does not post, pay, or send.
