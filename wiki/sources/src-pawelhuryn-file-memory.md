## Claims kept

Prefers git `.md` memory over a lab's built-in memory since March. Cowork, Claude Code, Codex, and Grok all read the same folder.

Four kinds of memory, three in files:

1. Semantic: markdown + index
2. Working: context window
3. Episodic: append-only log, then a table
4. Procedural: skills

Vector DB only when there is too much to read. Linked markdown is already a graph.

Setup: markdown + one CSV. No vector DB.
