## Claims kept

Reply to Steve Faulkner (@southpolesteve, 2091632440242573786). Body is a mention plus a quote of Alex Veremeyenko (@alex_verem, 2091165832592413114).

Faulkner asked for a computer-use flow: agent requests approval, then a password is injected into a browser field without entering the model context.

Quoted tweet: OpenConnector is an open-source gateway between an agent and apps. Credentials stay in the runtime. The agent gets a catalog of actions. Secrets never touch the model context. Controls named: allow/block policies, scoped connections, runtime tokens, redacted logs. Also named: MCP, TypeScript actions, Docker or Cloudflare self-host. Project called young.

Tweet counts (800+ services, thousands of actions) are `unverified`. No paper. Tweet did not link a repo. Do not bind this post to a GitHub URL.

Fits [[secret-gateway]] and [[harness-routing]] (permissions outside the weights). Same secret-exclusion as [[audited-task-contract]], at tool time.

Browser field injection and an API-action catalog are not the same mechanism. See [[contradictions]] C40.
