## Claims kept

`/ultra` runs a task N times in isolated git worktrees, then a same-model [[probabilistic-pivot-tournament]] picks a winner. Terminal-Bench, DeepSeek V4 Flash 0731, N=5, OpenCode run: 24% to 33% on 15 failure-skewed tasks; 40% to 75% on 4 recoverable tasks. Author-reported. Author estimates +2 to +5 on the full set where the model is already about 83%.

Reimplemented PPT from [[jacky-kwok]] (arXiv:2607.05391) with reasoned pairwise votes, no logprobs. Official paper-faithful code is TurboAgent.

Planning-first best-of-N: 0 of 5 outcomes changed. Dropped.
