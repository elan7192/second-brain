## Claims kept

AIP sits on Foundry data and the Ontology. Builder tools named on the AIP overview: AIP Logic, AIP Chatbot Studio (formerly AIP Agent Studio), AIP Evals.

The Ontology is an operational layer: semantic objects, properties, links; kinetic actions and functions. See Palantir ontology overview.

OSDK reads and writes Ontology objects from app code. SuperRepo declares object types in code. Developer Console is the hosted bootstrap. This vault has no Foundry enrollment and D5 forbids creating live Palantir objects.

build.palantir.com is an example library (Pipeline Builder, Workshop, OSDK to-do apps, document-to-ontology parsing). Sign-up for a free developer tier is a hosted Palantir account. Not done here.

[[foundry-3d]] is an arXiv paper on SuperTokens. Not Palantir Foundry.
