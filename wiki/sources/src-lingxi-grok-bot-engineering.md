## Claims kept

One domain per standing bot: sharper memory and specs inside the owned area. Bots can cross lanes, but focus beats a generalist that owns everything.

Cloud agent proof loop: launch with skills named and proof expected; stay on the run (read transcript, queue/interrupt); agent verifies its own result (screenshot before/after, CLI, tests); package a repeating path as a repo skill.

Treat the bot like a talented intern: short chat, study the area, refer to how other engineers did it. No giant prompt required.

Hands-off when blast radius is low; cautious on higher-risk actions. Author describes auto-merge for low-blast confident PRs — this desk keeps last yes human; no auto-merge.

Daily playbook nudge: ops bot runs morning 1:1s to reinforce playbook and surface blockers. This desk uses Morning OS / existing routines, not a new Jenny ops hire.
