## Claims kept

Every agent correction should be eliminated entirely, in this order of value:

1. Categorically eliminate the problem through better architecture or choice of data structures.
2. Turn it into a lint rule or test so CI catches it.
3. Turn it into a skill or rule.
4. Have humans review the code to catch it (last resort).

Principle: kill repetition. Architecture/data structure → lint/test CI → skill/rule → human review last.
