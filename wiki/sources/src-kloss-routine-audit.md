## Claims kept

Applied poteto quota tip; audited a mega-burning Grok Bot setup. Concrete checklist:

1. Audit routines for accidental 15-min schedules (~96×/day).
2. Check across bots for duplicate routines (same job on two bots).
3. Idle/inactive intent ≠ routines stopped — routines can run separate from bot chat.
4. Long main chat + attached routines re-read the whole chat each run — move recurring work off the long CoS thread.
5. Tag one bot in group channels (untagged → every bot answers → 3× cost).
6. CoS: send once; do not confirm + chase + confirm receipt (four messages for one job).
7. Batch skill evals; do not make every bot reread the whole skill file to check one thing.
8. Prefer a cloud agent writing a script once; bot runs the file — avoid long looping tasks inside chat.

Most burn was testing/setup/experiments. Author cost figure stays unverified. See [[grok-bot-quota]].
