# Botdirectory scan

Catalog scan of botdirectory.ai. Not a scout dump. Not a bot factory.

Source: [[src-botdirectory-picks-2026-08-27]]. 304 listings. Fetched 2026-08-27 06:39 Taipei.

## Method

Prefer a skill on an existing role. New bot only if a real work stream has no owner.

Every imported skill must declare: when, sequence, validation, output, approval gate, no-guessing.

Do not create bots, install plugins, or inbox anyone from a scan.
